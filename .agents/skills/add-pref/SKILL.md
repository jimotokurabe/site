# 県を1つ増やす

兵庫県41市町で作ったやり方を、ほかの県でくり返すための手順。
先に `CLAUDE.md`（守ること）と `TOPICS.md`（1つの制度の作り方）を読む。この手順はその2つより優先しない。

## できあがるもの

| ファイル | 中身 |
|---|---|
| `data/<県id>-menkyo-henno.json` | 返納特典（兵庫と同じ形）と、県の情報 `pref` |
| `data/<県id>-taxi.json` | 高齢者のタクシー代の助成（兵庫と同じ形） |
| `<県id>-menkyo-henno.html` / `<県id>-taxi.html` | `python3 tools/build.py` が作る |

県id はローマ字（例：`osaka`、`kyoto`）。市町村の slug もローマ字で、ヘボン式・長音なし（例：`sakai`、`higashiosaka`）。

## 流れ

| 段 | だれ | やること | 止まる？ |
|---|---|---|---|
| 1 | AI | 市町村の一覧・読み・地域分けを作る | |
| 2 | AI（並べて） | 地域ごとに、返納特典とタクシー助成を公式ページで調べる | |
| 3 | AI | 抜き書きを機械で照らし合わせる（`tools/check_quotes.py`） | |
| 4 | AI | 県全体のこと（県警の特典一覧・県内共通の割引）を調べる | |
| 5 | AI | データを書き、下書きのページを作って確かめる | |
| 6 | AI → オーナー | まとめと、確かめきれなかった市町村を見せる | **止まる** |
| 7 | オーナー | 「出して良い」 | |
| 8 | AI | `pref.draft` を消して本番へ。`TOPICS.md` の表を直す | |

### 1. 市町村の一覧

- 県の公式ページ（市町村一覧・推計人口）から、全市町村の名前・読み・人口を取る。数が合うか（例：大阪府は43）を必ず確かめる。
- 地域分けは、県が使っている分け方（例：大阪府なら「北大阪・東部大阪・南河内・泉州・大阪市」など）を公式ページで確かめて使う。1地域 5〜10市町村くらいになるように。
- 単位 `unit`：町村があれば「市町村」、市と町だけなら「市町」。

### 2. 地域ごとに調べる（AIを並べて走らせる）

地域ごとに1つずつ、調べる係（Claude Code なら Agent、Codex なら並列のタスク）を同時に走らせる。係に渡す指示は下の「調べる係への指示」をそのまま使う。

- 係は使用量の少ないモデルで走らせる（Claude Code なら Agent に `model: "sonnet"`）。照らし合わせ（3）とまとめ（5）は親が行う。
- 同時に走らせる係は3つまで。1県終わるごとに枝へ push する（利用上限で止まっても成果が残るように）。
- 1回の作業（5時間の利用枠）で調べられるのは約200市町村まで（東北6県・約230でぎりぎりだった）。

- 根拠は市町村の公式ページ（`*.lg.jp` や市町村のドメイン）と県・県警のページだけ。検索結果の要約・新聞・まとめサイトは根拠にしない。
- 抜き書きは、リポジトリの外 `副業/jimotokurabe-調査/<県id>/notes.json` に置く（公開しない）。
- 係の結果は、データの下書き `副業/jimotokurabe-調査/<県id>/draft-henno.json`・`draft-taxi.json` に地域ごとに足す。

### 3. 照らし合わせる

```bash
python3 tools/check_quotes.py ../jimotokurabe-調査/<県id>/notes.json
```

- NG の市町村は、係の結果を捨てて、その市町村だけ自分でもう一度公式ページを読む。
- 2回目も確かめられないものは、`flag` に確かめ方（「〇〇課（電話番号）で確かめてください」）を書く。
- ページの日付が1年以上前のもの、読み方が2通りあるものも `flag` に書く。

### 3.5 まとめるときに直すこと（大阪で分かったこと）

- 係が `url: "記載なし"` と書いてきたら、`url`・`src`・`upd` を消す（リンクのないカードになる）。
- `check_quotes.py` が通っても、`check_links.py` で出典が 404 のことがある（抜き書きは別のページから取っている）。404 の出典は消し、`flag` に確かめ方を書く。
- 「返納すると若い年齢から使える、高齢者向けの制度」は、返納特典の区分を `elder`（高齢者向け）にそろえる。
- 検索結果の要約にだけ出てくる特典（公式ページで見つからない）は採らない。`notfound` にして `flag` に窓口を書く。
- 地域分けは県の公式ページどおりにする（神奈川では、相模原市は独立した地域ではなく県央地域だった）。係に渡す前の想定とちがったら、まとめるときに直す。
- `check_quotes.py` の NG でも、ページの中で文字がタグで区切られているだけのことがある。NG は自分でページを開いて確かめ直す。
- 県が「市町村別の支援施策」のまとめページを出していることがある（埼玉など）。入口には便利だが、古い・抜けていることがある（埼玉では、市町のページで確かめ直したらタクシー助成が3つ見つかり、終わった制度がまだ載っていた）。根拠は市町村のページにし、まとめページしかないものは `flag` を付ける。
- タクシー助成の区分：介護の認定・体の状態が条件なら `care`。年齢に「地区」「免許を持っていない」の条件が付くだけなら `yes`（兵庫の加西市、神奈川の厚木市・小田原市に合わせる）。
- タクシー助成の区分（福岡で分かったこと）：返納特典の中身にタクシー券が選べて、年齢で使えるタクシー助成がないときは `henno_only`（兵庫の決め方）。予約して乗る乗合の交通（AIオンデマンドバス・乗合タクシー・デマンド交通）の高齢者料金はタクシー助成に含める。決まった路線を走るバスは含めない。
- 係は、検索結果の要約を「〜だけが対象」のような説明文に使ってしまうことがある。報告の unsure に「要約でしか確かめていない」とあるものは、説明文からその部分を消す。
- 東京で分かったこと：区（特別区）も市町村と同じに扱う（`unit` は「区市町村」）。地域の数の単位と「都内・府内・県内」は仕組みが自動で出す。東京都シルバーパスなど都道府県の制度は、区市町村の特典に入れない。区や市のサイトには機械のアクセスを断るところがあるので、確かめる道具はふつうのブラウザと同じ名乗り方をする。
- 係への指示は、調査のフォルダに共通の指示書（例：`副業/jimotokurabe-調査/saitama/brief.md`）を置き、各係には「対象の市町村と書き出し先」だけを渡すと短く済む。60市町村を超える県は、先に県全体の係だけを走らせて地域分けを確かめてから、地域の係を出す。
- 地域ごとの結果を1つにまとめる小さなスクリプト（例：`副業/jimotokurabe-調査/osaka/merge.py`）を、調査のフォルダに置くと、直してからまとめ直すのが楽。

### 4. 県全体のこと

- 県警の「運転経歴証明書の特典（サポート企業）」のページがあれば、`pref.statewide` に書く（形は `data/hyogo-menkyo-henno.json` の `pref.statewide` を見る）。なければ `statewide` を書かない（ページから欄が消える）。
- `pref.police`（例：「大阪府警」）、`pref.placeholder`（検索欄の例。その県の市町村のひらがな2つ、例：「例：さかい、とよなか」）。

### 5. 作る・確かめる

- 作業用のブランチを切る（`claude/<県id>`）。
- `pref.draft: true` を入れておく。下書きの間は、検索に出ない・サイトマップに載らない・下書きの帯が出る。
- `python3 tools/build.py` → 兵庫のページが変わっていないこと（`git diff --stat` で兵庫の html が変わっていない）を確かめる。
- ブラウザで、スマホの幅（390px）で横にはみ出さない・絞り込みが動く・市町村の名前で探せることを確かめる。
- `python3 tools/check_links.py <県id>-menkyo-henno.html` と `<県id>-taxi.html`。

### 6. オーナーに見せる

`CLAUDE.md` の「オーナーへの説明」に合わせて、次だけを短く：
- 特典が見つかった市町村の数、タクシー助成ありの数
- 確かめきれなかった市町村と、その理由（`flag` の一覧）
- 下書きのページの見方（ローカルのプレビュー）
- 次にやること：「出して良い」と返事をもらう

### 8. 本番へ

- `pref.draft` を消し、`python3 tools/build.py`、コミット（名前は Claude のまま）、PR、マージ。
- トップページに県を足すのは、2県目を出すときに一度だけやる作業（いまのトップは兵庫だけを出す作り）。オーナーに聞いてから。
- 本番に出たことを確かめ、`TOPICS.md` の表を直す。オーナーに Search Console でサイトマップを送り直してもらう。

## データの形

返納特典 `cities[]` の1件（兵庫の実物を見て合わせる）:

| キー | 中身 |
|---|---|
| `slug` `n` `y` `r` | ローマ字・名前・ひらがな・地域id |
| `k` | `give` もらえる／`discount` 安くなる／`elder` 高齢者向け／`purchase` 購入の補助／`end` 終了／`none` なし（「ない」と書いてあるときだけ）／`notfound` 記載なし |
| `what` | 1〜2文。やさしい言葉で |
| `amt` `age` `dl` | 特典があるときだけ。書いていなければ「記載なし」。申し込みがいらないなら `dl` は「申し込みはいりません」 |
| `apply_label` `apply` | 「申し込み先」か「問い合わせ先」と、課の名前 |
| `url` `upd` `src` | 出典・ページの日付（「2025年4月1日更新」など原文どおり）・出典の呼び名（省略可） |
| `note` `flag` | 補足・確かめ方（省略可） |

タクシー助成 `cities{slug: …}`：`k`（`yes`／`care`／`henno_only`／`end`／`none`／`notfound`）、`name` `what` `age` `amt` `how` `henno_link` `henno_earlier` `url` `src` `upd` `note` `flag`。区分の意味は `tools/build.py` の `TAXI_KINDS`。障害者手帳だけが条件の福祉タクシー券は入れない。

## 調べる係への指示（そのまま渡す）

```
あなたは「じもとくらべ」の調査係です。<県名>の<地域名>の次の市町村について、公式ページを開いて原文で調べてください：<市町村の一覧>

調べること（市町村ごと）
A. 運転免許を自主返納した人への、市町村独自の特典（券・カード・運賃割引・シニアカー購入の補助など）
B. 高齢者のタクシー代の助成（タクシー券・料金の助成・デマンド交通の高齢者料金）。障害者手帳だけが条件のものは除く

守ること
- 根拠は市町村・県・県警の公式ページだけ。検索結果の要約や新聞・まとめサイトは根拠にしない（入口として使うのはよい）。
- 書かれていないことは「記載なし」。推測で埋めない。「ない」と書かれているときだけ「なし」。
- 受付を終えたものは「終了」。いつ終えたかを原文どおり。
- 金額・年齢・期限・申し込み先は、原文の数字のまま。

返すもの（JSON）
{"henno": [<data/hyogo-menkyo-henno.json の cities と同じ形>],
 "taxi": {<slug>: <data/hyogo-taxi.json の cities と同じ形>},
 "notes": [{"slug","part":"henno"|"taxi","url","quote":"根拠の原文を20〜60字、ページのとおりに"}],
 "unsure": [{"slug","why"}]}
notes は、区分・金額・年齢を決めた根拠ごとに1つ以上。quote は要約せず、ページの文字をそのまま写す。
```
