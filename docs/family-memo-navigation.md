# 自治体詳細から家族向けメモへ

2026年10月31日。各支援の条件を読んだ人が、その場で共有文を確認・コピーできるようにした。対象は全国1,741自治体の免許返納・移動支援詳細。既存の家族用メモを使い、制度の再調査や確認日の更新は行わない。

## 使い方

- 支援の末尾に「この支援のメモを確認・コピー」を置く。今読んだ欄だけの条件・出典・確認日を含む共有文が開く。別の支援の保存状態は変えない。
- 「家族用メモに追加」は従来どおり市町村ごとに端末内へ保存する。追加済み件数と「まとめて確認する」リンクをその場に表示し、短時間の通知だけに頼らない。
- 支援一覧から「家族用メモ・共有の使い方」へ進める。選択済みの一覧のすぐ下へ既存のコピー入口を移し、チェックリストより先にメモを確認できる。
- 未選択なら、このページのURLと主な出典をコピーする従来の機能へ進める。「選んだ支援の全文」と「ページの案内」をボタン名で分ける。
- コピーした内容をLINEやメール等に貼り付けて共有する。外部アプリへの自動送信は追加しない。

本人と家族が一緒に確認する既存の方針、深緑・セージ・アイボリーを維持する。制度本文と区別した余白・説明・濃い緑のボタンを、既存の支援欄の末尾だけに設ける。固定表示や会話の絵への重なりは増やさない。読み終えた場所から必要な行動へ進める設計判断であり、利用者効果の実測ではない。

## 内容と操作の保持

共有文は既存の `.original-record` 全文から作成し、閉じた出典欄も含める。選んだ制度の一部だけを抜き出したり、複数の支援金額を合算したりしない。掲載が未確認の項目も元の説明どおりで、受給可能という判定はしない。

直接開いたメモも、複数をまとめたメモも同じ既存の生成・コピー処理を使う。閉じると押したボタンへ戻る。保存不可ならそのページを開いている間の選択で作成でき、自動コピー不可ならメモを選択して手動コピーできる。コピー成功イベントは成功時だけ送る。JavaScriptなしでは従来どおり全支援本文を表示する。

## 計測

既存の `memo_copy` / `feature_type=selected_supports` を維持し、新たに次の2イベントを追加する。引数はコード内の入口種別 `support_panel` / `family_section` のみで、本文・選択ID・件数・チェック内容・入力値を渡さない。解析URLのクエリ/ハッシュ除去、ローカル/下書き除外、既存オプトアウトを維持し、プライバシーポリシーへ説明した。

| イベント | 条件 | 数え方 |
|---|---|---|
| `family_memo_view` | 支援末尾の操作領域または選択一覧の25%以上が画面に入る | 入口種別ごとに1ページ表示につき1回 |
| `family_memo_open` | 支援本文を含む共有メモの表示完了 | 実際に開くたび、押した入口種別を記録 |

未選択時のURL・主な出典だけの既存案内ダイアログは新しい `family_memo_open` に含めず、従来のコピー成功 `feature_type=city_guide` で区別する。IntersectionObserver非対応の環境では閲覧を推測して送らない。ブラウザ表示は利用者が内容を読んだことの証明ではない。

公開当日の開発確認を一般利用の成果と数えず、公開後の同じページ・期間・端末で入口表示人数、メモ表示人数、コピー成功人数、公式情報への移動を併せて見る。複数のイベント件数を単純に割って人単位の転換率にしない。新イベントの公開前実績は存在しない。GA4側のカスタム定義やキーイベント設定は変更しない。

## 検証

`test_family_memo_dom.cjs` は生成した神戸・横浜・札幌・大宜味の実DOMとスクリプトを使い、単独と複数のメモ、条件・出典・確認日、保存復元/保存不可、閉じる際のフォーカス、コピー失敗、閲覧前の未送信・重複抑止・未知の引数拒否・ローカル解析除外を確認する。

通常生成は `python3 tools/build.py`。計測JSの内容ハッシュが変わるため、全公開頁の計測スクリプトURLも更新される。自治体以外の制度本文を変更する目的ではない。

公開基点 `01b7555fc6eabc9cf38648783e3d3724d89ed2a7` と比較し、1,741自治体の保護領域15,669件、全ページの既存97,206アンカー、データ・公開カタログ・ホスティング201ファイルを保持。自治体以外の463頁は計測スクリプトURLを除いて同じDOMで、別途プライバシーの説明を更新した。2,205公開頁・SEO・47県バス検査、支援表示10/計測生成2テスト、実DOMの新旧計測・共有操作検査を通過。全国原文検査は基点にもある神戸ICOCA終了注記の完全原文不一致1件のみで、本文欠落は増えていない。

ブラウザーで神戸の単独メモ表示・コピー成功表示・押した位置への復帰、2項目をまとめる流れを確認。神戸の390px通常/320px文字拡大、大宜味の320px文字拡大、横浜の390px通常でページ/メモに横はみ出しなし。横浜の未確認という説明も共有文に残る。コピー後にも「閉じて戻る」を押せるよう、メモ下部にも閉じる操作を置いた。OS全体のクリップボード内容一致・実紙印刷・GA4管理画面での新イベント受信・利用増加の効果は未確認。
