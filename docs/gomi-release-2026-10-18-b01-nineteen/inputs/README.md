## 選定理由と区別

- 川西は戸別支援の資格・同資格者のみ世帯の例外、通常大型の有料予約、市公式によるシルバー人材センターの有料屋内搬出紹介、国崎への家族持込を分ける価値があります。サポート収集の対象ごみ・費用・室内対応等は原典未記載のまま。屋内搬出紹介を市収集や無料支援にしません。
- 姫路は高齢者等の4条件、障害の2条件、妊産婦の2条件を別枝とし、共通要件との関係を保持。ふれあい収集は可燃ごみ・週1回・屋内不可。現地調査の第三者立会いと通常日の立会いを区別します。
- 姫路の通常粗大と持込は旧姫路、夢前/香寺/安富、家島を区別。市川美化センターへ粗大は不可。粗大の室内搬出制度は今回の市公式範囲では未確認として、制度不存在とは断定しません。
- 国崎は既存保存原典の川西市を含む1市3町適用を確認し再利用。2027年1月の料金改定予告、家族の搬入と本人確認書類、ネット申込、自己荷下ろしを補いました。市の古い電話案内だけで施設の追加条件を落としません。
