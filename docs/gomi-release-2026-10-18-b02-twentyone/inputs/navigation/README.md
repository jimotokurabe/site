# ごみ支援の地域入口（2026-10-18・未公開）

ごみ支援にも「全国 → 都道府県 → 市町村」の入口を設ける依頼を受け、既存21地域候補でプレビューを作成しました。本番は19地域のままです。京都・広島の候補を含みますが、その公開承認や本番反映はしていません。今回の制度情報変更はゼロです。

## 画面

- 全国のごみ入口は地方別47都道府県タイルが主。掲載10都道府県だけ県ページへ進み、未掲載37県は共通説明へ移動します。未掲載を制度なしとせず、空の県ページを作りません。「掲載準備中」ともせず「未掲載」と表示します。
- 市町村名検索は補助の折りたたみに移動。かな・カタカナ正規化、件数・該当なし表示は既存JSを維持しています。都道府県名は既存の地域マスタを参照し、pref_name未設定地域でも内部IDを表示しません。
- 掲載県のページはその県の市町村カードだけを表示。各市のパンくずはトップ → ごみ出し支援 → 都道府県 → 市町村とし、市町村を選び直すリンクを付けました。
- トップのごみブロックは「都道府県から探す」を主CTAにし、全市列挙を除きました。他の本文・免許返納の地域入口・リンク・計測はそのままです。

配色・書体は既存のアイボリー、セージ、深緑と日本語本文を継承。地域タイルは階層の選択、4種のピクトグラムは各市内の経路選択に役割を分けています。別テーマの見た目やイラストを増やしていません。改善効果を実測したものではありません。
