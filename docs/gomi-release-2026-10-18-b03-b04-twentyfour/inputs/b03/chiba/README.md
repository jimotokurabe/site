# 千葉市ごみ支援調査（2026-10-18）

## 結論

千葉市は千葉県の初候補として資料充足度が高く、4経路を公式資料で分けてプレビュー化できる。日常支援の資格条件、登録団体が活動する地域に限られること、粗大ごみ室内搬出の世帯条件・除外品、通常収集と持込みの品目別料金を確認できた。公開採用は未審査で、このデータは候補下書きとして公開不可。

- 日常ごみ：高齢者等ごみ出し支援事業。単身世帯を基本に、同様の要件を満たす同居人がいる場合を含む。資格要件のいずれかと、居住地域の登録団体が活動していることが必要。週1回以上の地域ボランティア収集だが、市内全域をカバーしない。
- 粗大ごみ室内搬出：身近な人の協力を得られず自力で運び出せない対象世帯向け。申込後に現地確認し、収集日を調整。家電リサイクル品、玄関から出せない物、取り外し・解体が必要な物などは対象外。
- 通常粗大ごみ：戸別収集は予約制で1回10個まで。品目に応じ390・780・1,170・1,560円。朝8時までに指定場所へ出し、通常収集の立会いは不要。
- 自己搬入：環境事業所での粗大ごみ持込みは市民対象、環境事業所は1回10点・1日10個まで、品目別手数料。搬入者は本人または条件を満たす代理人。市外在住の親族による代理搬入は本人・搬入者双方の本人確認資料等を求める案内あり。

## 選定理由と充足度

初の千葉県候補に必要な4経路が揃い、自治体の制度説明だけで各経路の違いを示せる。とくに日常支援の地域限定マッチングと、室内搬出支援の現地確認・対象外品が明記され、利用可否を誤解させずに案内しやすい。一般のごみ出し支援、粗大ごみ室内搬出、通常収集、持込みを別カードで扱える。

調査は公式サイト内検索6クエリ、保存資料8点。窓口確認・人手による全項目原文照合・独立レビューは未実施。候補としては充実しているが、地域ごとの登録団体の受入れ状況や室内搬出の個別判断、支援自体の費用は問い合わせが残る。現行validatorは `www.city.chiba.jp` を自治体公式ホストとして登録しておらず、未加工データでは全8出典URLを拒否する。コードを変更せず、同じvalidatorにURLホストだけを一時的に自治体ドメイン扱いさせた検査では、他のスキーマエラーはなかった。市ホスト許可後に通常validatorを再実行する必要がある。

## 保留・利用者への確認事項

- 日常支援：居住地域の登録団体が現在受入れ可能か、訪問方法、費用負担、声かけの希望や頻度。
- 粗大ごみ室内搬出：追加料金・免除の有無、世帯条件の判定、品目と搬出経路、訪問・収集時の立会い。
- 自己搬入：施設の現在の受付状況、本人運転の要否、対象品目や代理搬入時に必要な書類。
- 今回の公式資料では手数料免除制度の条件を確認できなかった。「制度なし」ではなく未確認としている。
