# B03 独立原典レビュー（2026-10-18）

千葉市・さいたま市の初稿各4経路、計80項目を、保存済み公式資料から独立に照合した。対象は両市の `original-draft.json` に固定する。対象条件のAND/OR、家族の援助、屋内搬出、料金、持込み時の本人・運転者、申込と窓口を重点確認した。調査者の草稿に対するAIレビューであり、人手確認や窓口確認ではない。

初稿で見つかった必須修正は `review-b03.json` の `required_findings` を参照。千葉の自己搬入には、若葉・緑環境事業所の2026-10-13再開、代理搬入、「1日10個」の上限を反映した。さいたまの自己搬入には、予約なし搬入を認める障害者向け例外と、10kg超の場合は最初の10kgから料金を計算する条件を反映し、予約制の表現を「原則として」に調整した。千葉の日常支援で引用する公式PDFと抽出テキストは、既取得資料の名称修正によって保存先へ復元され、ロケーター記載のSHA-256と一致した。必須6指摘は現候補で解決した。

その他の項目は保存原典の該当範囲と整合した。さいたまの「屋内搬出支援未発見」は確認した検索範囲だけの結論で、制度が存在しないという判定ではない。千葉の一般自己搬入ページには同じページに再開告知と古い停止表示が残るため、日付付きの再開告知を優先し、施設への事前確認を維持する。料金・手続きの将来変更や個別の利用資格までは保証しない。

修正後は、変更した項目だけ原典へ戻して再検査する。修正差分の再検査を、初稿80項目の全件再検査として数えない。公開承認・人手確認・現地窓口確認は行っていない。
