# 取り込み・レビュー用メモ

この担当はさいたま市の調査資料だけを作成した。入力は `new-city.json` 1市で、既存候補の他市データや共通コードは変更しない。

レビュー担当はまず `sources/` の原典保存ファイルと `review-locators.json` の対応位置を照合する。重点確認箇所は、ふれあい収集の単身/同居4枝、粗大ごみ屋内搬出不可と独立支援未発見の違い、直接持込みの「ご本人が持ち込む」条件、処理料金の適用期間・税込表示・戸別収集料金との区別。疑義は該当原典と行番号に紐付けて差分修正し、独立レビューの結果を別記録へ残す。

親側の集約入力に使う場合は、レビュー完了までは `ai_draft: true`, `draft: true`, `not_for_publication: true`, `review_status: ai_draft` を維持する。公開データへの統合、本番HTML再生成、公開承認の設定は本資料の作業範囲外。現行repoの `tools/validate_gomi.py` で草稿スキーマを検証でき、`tools/build_gomi_preview.py` でこの市だけのnoindexプレビューを再生成できる。プレビュー結果は対象repo外のこの作業フォルダに限る。
