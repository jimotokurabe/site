## 判定

岡山市は岡山県の初候補として、公式資料上で日常ごみのふれあい収集、粗大ごみの屋内搬出支援、通常の粗大ごみ戸別収集、粗大ごみ自己搬入の4経路を区別できる。候補データは調査用のAI下書きであり、公開不可・人手未審査。
