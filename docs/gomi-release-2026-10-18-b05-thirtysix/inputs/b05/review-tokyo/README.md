# 東京4区の独立AI原典レビュー（2026-10-18）

対象は杉並区・練馬区・板橋区・大田区の4区、16経路、計160項目と相談質問です。各区の初稿を `../{slug}/original-draft.json` に保全し、保存された公式原典へ戻って双方向照合しました。レビュアー自身が `corrections.json` に記録した指摘限定の修正を行い、修正後の `new-city.json` と `review-locators.json` を再照合しています。練馬区・板橋区は日常戸別収集の公式ページを追加取得し、初稿の「未発見」を訂正しました。

`review.json` の accepted はAI調査草稿としての採用判断です。人手の原文全件照合・窓口確認・公開承認を意味しません。親担当が重要な修正を点検してから `ai_reviewed` 化します。原典のSHA-256と取得時刻は `consumption.json`、区別の所見と修正範囲は各 `{slug}.json` を参照してください。モデルtoken・credit・調査費用は未計測です。
