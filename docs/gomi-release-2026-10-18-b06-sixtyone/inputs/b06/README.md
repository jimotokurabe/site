## 根拠と検証

各市の `official/` に自治体公式原典の原本と抽出テキスト、`official-metadata.json` にURL・取得日時・更新日・SHA-256を保存しました。採否と候補ハッシュは `selection.json`、独立照合の範囲・修正・保留理由は `review-east/`、`review-central/`、`review-west/` にあります。初稿とレビュー者自身の限定修正は各市の `original-draft.json` または `new-city.original-draft.json` と `corrections.json` で追跡できます。修正後の原典再確認は行いましたが、追加の独立全件レビューや人手原文確認ではありません。

`generation-input.json` は採用25市の入力版を固定しています。`verification.json` では、候補のスキーマ検証にエラーがなく、公開承認ゲートが正しく拒否することを確認しました。既存36市・206原典を保持し、候補全体で2,450項目・434件の制度と出典日付・414問の一致を確認しました。公開済み交通ページは再生成していません。ごみ支援41件とanalytics 2件、計43件のテストが成功しました。`browser-qa.json` では225表示条件の横はみ出しなし、100経路の印刷用DOMと相談メモの一致を確認しました。コピーは99件で初回一致し、青森1件は成功表示後の別呼び出しで再確認して一致しました。実紙印刷とネイティブ印刷ダイアログは未確認です。全国→香川県→高松市の操作と、高松の期限・地区・1回510円の記載も確認しました。`parent-spotcheck.json` は高松の保存公式原典との部分照合、`preview-takamatsu-mobile.png` はモバイル表示の記録です。

最終候補 `candidate.json` のSHA-256は `735a70a234a087c466189a4bd0effb7031a4017948a54c87c384475ee6e1266a` です。採用25市の制度だけを `ai_reviewed` としたプレビュー候補で、人手確認・窓口照会・本番公開承認ではありません。
