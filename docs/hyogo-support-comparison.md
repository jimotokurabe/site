# 兵庫県41市町の支援比較

2026年10月31日。兵庫県の既存URL `hyogo-menkyo-henno.html` に、返納特典・バス助成/敬老パス・タクシー支援を切り替える比較欄を追加する。他県の一覧と1,741自治体の詳細は変更しない。Issue #206 の県別統合方針のうち、今回の対象は兵庫県のみ。

地域選択＋家族機能という採用方針を維持し、県のページを読むだけで支援の内容・金額・主な条件を並べて知ることを目的とする。名前や地域の既存の絞り込みを共用し、「神戸、明石」のように空白/読点/カンマで区切った複数の名前・よみがなにも対応する。入力は画面内で処理する。

## 表示内容

返納41行、バス54行（45制度と制度未確認/終了等9行）、タクシー41行。返納以外にも対象がある高齢者支援や、介護等の条件付き支援はその状態を表示する。県共通の証明書による割引は、市町独自の特典と分けて案内する。

金額は元の文章をそのまま表示し、1回限り/年額/利用期間、デポジット、本人負担、予算・申請期限・選択制の条件を落とさない。金額順のランキングや合算を作らず、未確認を0円/制度なしへ置き換えない。神戸のICOCA配布終了、西宮の市独自返納特典なし、姫路の返納特典未確認を区別する。複数の欄に同じ制度がある場合も追加給付とは数えない。

各行から市町の該当する支援欄、注意事項と全公式出典へ進める。出典ごとの確認日・更新日と手順案内の確認日は別に表示する。主な対象条件の比較であり、居住地・所得・介護・除外・併用等を含む個別の受給判断ではない。今回は公開済みの掲載データから表示を生成し、全制度の確認日を更新しない。

元データは既存の `data/hyogo-menkyo-henno.json`、`hyogo-bus.json`、`hyogo-taxi.json`。`tools/prefecture_comparison.py` で比較用の構造にし、`national_navigation.py` から兵庫県だけに適用する。通常どおり `python3 tools/build.py` で生成する。

## 操作・アクセシビリティ

標準のラジオボタンとlabelで支援の種類を選ぶ。幅が狭いときは表を1件ずつ縦に並べ、列名を併記する。内容や条件を横スクロールの外へ隠さず、文字拡大とキーボード操作を維持する。JavaScriptなしでは3種類すべての表を表示する。

市町ページの一覧は開閉式で残し、従来のリンク・ページ内アンカー・県の返納手順・家族向け案内を保持する。印刷前に比較表の注意事項・出典を開き、印刷後に開閉状態を戻す。実紙印刷は別途確認が必要。

比較欄の市町詳細への移動は既存の `related_support_click`、公式出典は既存の `official_info_click` で計測する。新しいイベントやGA4設定は追加しない。検索入力・支援の絞り込み値は解析へ送信しない。新しい比較欄に付けた詳細移動件数を、未計測だった旧一覧の操作件数と同じものとして前後比較しない。
