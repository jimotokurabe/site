# 全国47都道府県の支援比較

2026年10月31日。兵庫県で公開した返納特典・バス助成/敬老パス・タクシー支援の比較を、既存の全47都道府県ページへ適用する。対象は1,741市区町村で、個別の自治体ページの内容は変更しない。

比較欄の種類切替、複数名/かなと地域による絞り込み、0件と解除、スマートフォンでの縦表示、印刷前の出典展開、旧一覧・旧リンクを共通処理へ統一する。都道府県名・地域数・市町村等の単位・検索例・詳細リンクは、その都道府県のデータを使用する。兵庫県の名称・件数・URLを他県へ転用しない。

## 表示する記録と条件

返納1,741行、バス2,557行、タクシー1,741行の計6,039掲載記録。未確認・終了・独自支援なし等の掲載状況も含み、6,039件の現行制度があるという意味ではない。バスは複数制度を別々に表示し、現在の条件を確認できていない記録は、その状態を金額欄の近くでも明示する。

金額、年額/1回限り、預り金、本人負担、利用期間、対象、申請期限、注意事項、出典と確認日は、元の掲載記録を保つ。支援概要と手順案内の給付・費用欄の双方を残し、預り金や本人負担を折りたたみの中だけに置かない。券の有効期限を申請期限へ読み替えない。

都道府県共通の案内は、出典が記録された内容だけを別欄に置く。記録がない場合に割引を推測して補わない。金額の合算・ランキング・個別の資格判定は行わない。今回の作業は公開済みのデータの表示改善で、全国全制度の再調査や確認日更新ではない。

## 生成と既存機能

`tools/prefecture_comparison.py` が都道府県IDを受け取り、各県の既存返納/バス/タクシーJSONから生成する。`tools/national_navigation.py` から全47県へ適用する。通常どおり `python3 tools/build.py` でHTMLを生成する。共通CSS/JSの参照を更新し、旧キャッシュでも不具合が出にくいよう市町村の単位には既定値を持たせる。

地域選択＋家族機能、深緑・アイボリー、既存の県手続き・家族案内・一覧・ページ内アンカー・canonical・サイトマップを維持する。個別自治体のメモ/共有、試算未対応地域の案内、3市の検索用文章を保持する。

比較欄から市町村詳細/公式出典への移動は既存の計測を使う。検索入力や絞り込み値を解析へ送らず、新イベント・GA4設定・定期監視は追加しない。新たに計測対象にした一覧の操作数と、以前の未計測の一覧を同じ指標として前後比較しない。

## 検証

兵庫県の8テストに加え、全47県の対象地域・全バス制度の金額/本人負担/対象/注意、タクシー条件・確認日、詳細リンク、要確認表示を検査する。生成した全47県の実DOMと実スクリプトで、件数・種類切替・複数名・地域とのAND・0件/解除・リンク先・既存計測と入力非送信を確認する。これらは掲載情報の現行性の再調査や、利用者効果の実証を代替しない。

公開前の基点 `81df41c4545307e6f4b888b05cf61a2507c5f711` と照合し、対象外2,158HTML（全1,741自治体詳細を含む）・201データ/カタログ/ホスティングファイルがバイト一致。全頁の既存97,215アンカー、47県の手続き・家族案内141領域、旧リンク・canonical・sitemapを保持。6,039行の金額・条件・注意・全出典/確認日を生成元に全件照合した。

13テスト、全47ページの実DOM操作と従来の兵庫県操作検査、2,205公開頁・SEO・47県バス検査が成功。全国原文検査の神戸ICOCA終了注記の完全原文不一致1件は基点にも存在し、新規の市町村本文欠落ではない。

ブラウザーで全47県×3種類＝141条件を320px文字拡大で確認し、横はみ出し・見出しの幅崩れ・件数違いなし。北海道・東京・大阪・香川・沖縄・兵庫は390px通常でも3種類ずつ、計18条件を確認。東京の複数名/0件解除/旧千代田区アンカーも確認した。実紙印刷・利用者効果は未検証。
