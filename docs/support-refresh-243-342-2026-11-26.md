# 流入順243〜342位・100自治体の公式再確認（2026-11-26）

既存の検索流入順位243〜342位を対象に、掲載済みの自治体・都道府県の公式資料と、交通事業者の公式運行案内を確認した。交通手段、券の用途、制度改定の前後で変わる条件を照合し、取得できない資料や記載のない条件については未確認を維持した。GA/GSCの再取得・電話照会は実施していない。 [調査 Issue #313](https://github.com/jimotokurabe/site/issues/313)

未確認表示には比較表の「掲載調査では未確認」「条件など要確認」「現在の条件は要確認」を含む。資料を照合できた制度でも、不足額の精算や利用期限など原文にない条件は未確認と記載した。
