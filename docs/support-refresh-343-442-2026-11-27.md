# 流入順343〜442位・100自治体の公式再確認（2026-11-27）

既存の検索流入順位343〜442位を対象に、掲載済みの自治体・都道府県・交通事業者の公式原文を照合した。旧版しかない資料や未記載、取得不可、資料間で表記の異なる条件は未確認を維持した。GA/GSCの再取得と電話照会は行っていない。 [調査 Issue #320](https://github.com/jimotokurabe/site/issues/320)

**42自治体・46カテゴリ**（返納2・バス42・タクシー2）を更新。全国の比較6,043行のうち未確認表示は **2,834 → 2,796件（38件減）**。対象100自治体では **189 → 151件（38件減）**。
未確認表示は比較表の「掲載調査では未確認」「条件など要確認」「現在の条件は要確認」の合計。資料を照合した制度にも、記載のない利用期限・支払い方法・適用区間などを個別に記録した。

## 主な訂正

- **下仁田町**。11月1日に予約制「ねぎまる」が実証運行を開始。町内在住70歳以上は1回100円。平日朝夕の定時スクールバスは無料。旧運行の返納者無料が新体制で適用されるかは未確認。 [町の運行案内](https://www.town.shimonita.lg.jp/kikaku-zaisei/m02/m02/m01/demandbus.html)
- **深川市**。利用登録は初回300円で印鑑・身分証明書は不要。10枚単位で購入する助成券に利用期限なし。滝深線は廃止され、対象券の払い戻しが案内されている。 [市のバス利用料金助成案内](https://www.city.fukagawa.lg.jp/cms/section/kourei/ik75k4000000113m.html)
- **小林市**。市の令和8年5月改正時刻表で、宮交スマート65も提示すると100円と確認。返納者運賃は市時刻表で100円、3年間。過去に記録された県警一覧の半額表記との関係は未確認。 [市の改正時刻表](https://www.city.kobayashi.lg.jp/material/files/group/6/komibasukaiseigojikokuhyou.pdf)
- **裾野市**。通常の助成券2,000円分は令和8年度も交付。別の物価高騰対策の3,000円分は令和9年1月31日まで、現金払い時に通常券と併用できる。 [市の物価高騰対応事業案内](https://www.city.susono.shizuoka.jp/kenko/4/22333.html)
- **郡山市**。共通券をバス・タクシーに使えるのは年度内75歳以上。年最大10,000円分。初年度は申請月によって20・16・10・6枚、次年度以降は4月に20枚送付。 [市の健康長寿サポート事業](https://www.city.koriyama.lg.jp/soshiki/66/3008.html)
