# 未確認支援の全国調査・第1回反映（2026年10月31日）

先行13自治体の更新（#263）に続き、34都道府県・90自治体の95記録（市区町村×種類）を公式資料に基づいて更新する。内訳はバス61、タクシー24、返納10。同じ自治体の複数制度を含むため、制度数とは一致しない。別に、滋賀県共通の令和8年度WESTERポイント支援の受付終了を補足する。

全国の未確認表示をすべて確認済みにする更新ではない。自治体本文の該当段落を確認したものと、県・県警が記載する当該自治体欄まで確認したものが混在する。県の一覧にないことは制度の不存在を意味しない。県一覧だけでは分からない個別条件は、取得済み自治体本文で追加照合を継続している。

- 返納欄に既にあったタクシー券をタクシー欄へも掲載し、返納者限定と返納以外の対象者も含む制度を分ける。両欄の金額は合算しない。
- 江東区等の先行更新と同様、本人負担・預り金・1回限り・選択制・世帯単位・申請期限と券の利用期限を保つ。金額が確認できても、細則の未記載や資料間の相違が残る場合は具体的な未確認点を残す。
- 立山町の返納支援の新規受付終了、粟国村の旧コミュニティバス廃止、長泉町の旧バス券制度の統合を、別の現行交通支援と区別する。宇都宮市の令和9年度開始予定と摂津市のジャンパー交付終了予告は、現在使える給付・終了済みの制度に読み替えない。
- 返納者向けタクシー券でも年齢・金額・申請方法を既存一覧に出力する。確認した記録・出典の日付だけを更新し、県全体や未照合の手順・他制度の確認日は保持する。
