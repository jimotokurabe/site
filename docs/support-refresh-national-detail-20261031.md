# 未確認支援の全国調査・詳細確認の反映（2026年10月31日）

検索で見られている自治体を先行更新した後、全国47都道府県の未確認表示3,153記録を分担調査した。これは市区町村×支援の種類・複数のバス制度を含む掲載記録であり、自治体数や制度数ではない。

3,153記録すべてに調査の結論を記録した。内訳は、公式原文の当該段落・表等を確認した2,907記録、公式索引や検索等を範囲を限って調査した160記録、公式原文を取得できなかった86記録。過年度資料や関連制度の確認を含み、全制度の現行性・金額・個別条件が確定したという意味ではない。資料にない条件、現年度の継続、資料間の相違、取得できない原文は未確認として残し、確認日を一括更新しない。

全国調査から38都道府県129自治体の145記録（バス75、タクシー41、返納29）を更新した。先行13自治体を合わせた更新は計142自治体。この回は第1回反映（#265）から追加・詳細化した23都道府県45自治体の52記録（バス16、タクシー17、返納19）を反映する。同一記録の再更新を含むため、第1回95記録との単純な合計ではない。滋賀県共通の受付終了と立山・粟国の関連補足は第1回で反映済み。

## 利用判断に関係する訂正

- 南知多町：旧一日券の案内と区別し、現行IC敬老パスの運賃、1,000円の預り金、対象・手続きを具体化。免許を持ったことがない方も対象なので返納者限定としない。
- 奥出雲町：交通利用券50,000円分、電動車いす購入補助上限50,000円、商品券10,000円の選択制・1人1回。65歳以上・町内居住・全免許返納、原則返納後1年以内の申請と券の使用期限を分ける。
- 小千谷市：免許を持ち、日常運転する方が返納前に1か月試す事業。返納後にもらえる特典と取り違えない。募集総数を1人当たりの給付数として表示しない。
- 豊見城市：新規申請終了と、交付済み券の利用期限を分ける。南風原町等の別制度まで終了したとは扱わない。
- 安芸高田市・春日市・大崎町：終了した旧返納支援と、別の高齢者交通支援や運転装置補助を分ける。
- 輪之内町：上限3,000円には本人負担300円を含む。対象病院等の条件を明記し、低額運賃に関する資料間の相違は残す。
- 矢巾町・一関市・九戸村：県警の移転した自治体支援PDFを修復。資料の基準日、確認日と不明な発行日を区別し、九戸村の媒体・実利用額等の不明点を残す。

県比較にも追加の公式出典を表示し、その出典固有の確認日を保つ。自治体詳細、県の比較、一覧、家族に渡す掲載記録は同じデータから生成する。金額を合算する機能や試算対象は追加しない。
