# 検索流入順100自治体の公式再確認（2026-11-02）

既存GSC順位43～142位の100自治体を3担当で調査。既存の未確認152自治体カテゴリを起点に、関連する既知の制度との矛盾も確認した。GA/GSCの再取得や電話照会は行っていない。Issue #303。

96自治体・126自治体カテゴリを更新。全国比較6,041行中の未確認表示は3,054件から3,004件（50件減）。原文で内容を確認できたという意味であり、資料にない条件を推測で埋めていない。制度の未発見と不存在、障害・介護条件付き助成、返納者限定、民間特典を区別する。

## 主な訂正

- 沼津：65歳以上・有効免許返納後6か月以内のバス/タクシー券5,000円を返納者限定と確認。令和8年度交付分は令和10年3月31日まで。
- 長野：70歳以上の市民が対象の乗合タクシー割引をタクシー欄にも反映。一般のメーター制タクシー助成とは区別。
- 高浜：65歳以上会員向け1,500円分/購入1,000円の共通チケットは指定タクシーにも利用可能。市内乗降・平日7:30～17:30・他補助併用不可を併記。
- 葛飾：10月23日更新の原文では予定枚数に達して返納支援の新規受付終了。旧期限の計算・申請書誘導を除去し、警察での返納手続きと区別。かつライド等を終了扱いにしない。
- 犬山：現行85歳以上のパスと12月1日から75歳以上に変更予定を分離。未来の条件を現在適用しない。
- 北秋田：広報PDF画像を再照合。じょうもんパスの米内沢・鷹巣両販売窓口を保持し、事業者現行価格と照合。
- 喜多方：返納券交付から5年の有効期限、事業令和9年3月31日まで予定を補完。

## 未解決の扱い

多可町・亘理町・東郷町は必要な制度原文を今回取得できず、制度内容・確認日は従来のまま。多可・亘理には取得不能の確かめ方を追記した。倉敷・石垣・小鹿野は原文の一部を読めても未確認内容を確定できず、既存データを維持した。市原は県の現行資料で共通割引を照合し、市本文未取得の注意は保持。朝来の対象年齢不一致（#304）、小山の取消枠の市県不一致（#305）は明示して残す。
