# 移動費の目安（全国入口）

2026-10-15。手入力を増やさず地域の支援による費用差を知りたい人向け。`transport-cost.html` で47都道府県・1,741市区町村を選べる。自動計算は12道県26自治体・28種類。計算に必要な条件が未整理の地域は結果を消して既存の支援内容と自治体詳細を案内し、支援なし・0円としない。

2026-10-31の導線修正では、市町村詳細の試算リンクを対応自治体に限定。未対応自治体は「行き先と往復の費用を整理する」から、都道府県・市町村を引き継いだ既存のお出かけ計画へ案内する。自動試算に未対応であることと、調べた交通手段・費用をまとめる用途を併記する。対応状況は `load_estimates` で試算の出力と同じ採用済みルールを読む。地域や金額を別の一覧に二重管理しない。

試算ページも選択前に一部自治体のみ対応と説明し、地域候補に「試算あり／自動試算なし」を表示する。未対応を選んだ場合は、支援がないという意味ではないことを残し、お出かけ計画へのリンクを掲載情報より前に示す。対応地域へ切り替えると未対応案内のリンク先を消す。計算ルール・制度の原文・確認日・既存の成果計測は変更しない。

既存10自治体12種類を `data/transport-estimate-verified.json` に保持。今回再確認をしていない掲載記録から追加した16種類は `data/transport-estimate-reviewed.json` に分離した。確認日を変えず、元の対象条件・全文・出典を画面と共有メモから参照できる。追加は券4件、固定運賃5件、率引き7件。自治体をまたぐ制度や選択制の制度は自動合算しない。

券の全年度分を未使用から使う例を標準にし、片道料金・月の往復回数は3択ボタン。取得済みの乗車証の乗車料金だけの比較では取得費を含まないと明示。年間負担減・自己負担・月平均・12か月推移を表示する。開始月・残数・期限や個人資格を入力させず、実受給額は確定しない。相生市の券は一回限り。料金は距離や現行路線運賃からの推計ではなく比較用の例。

## 更新

- 通常の `python3 tools/build.py` がテンプレートとルールからページ・公開用JSON・全国導線を生成する。
- `tools/transport_estimate_rules.py` は掲載記録から保守的な定型候補を抽出する補助。通常buildでは自動実行しない。実行した際は追加・削除・根拠をレビューしてから採用する。数字があるだけで計算対象にしない。
- `tools/transport_cost.py` は追加16ルールの対象レコードの選択可否・確認日・支援内容・出典が変わると再確認を要求する。検証済み10自治体は公式再確認に基づく個別管理のため、元カタログと条件差がある場合も元の掲載記録を書き換えない。
- 回数上限不明を「制限なし」とみなさない。乗合交通そのものの運賃を助成額として計算しない。支援が確定しないものは案内に留める。
- 料金・回数・検索語は画面内のみ。選択した公開地域IDだけURLに反映。メモの自動送信なし。表示サイズは既存と同じタブ内設定を引き継ぐ。
