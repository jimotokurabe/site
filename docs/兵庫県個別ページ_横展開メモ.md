# 兵庫県の個別ページ：移動支援の横展開メモ

## 対象と目的

公開済みの多可町を除く、兵庫県の免許返納手順ページ29件に「返納後の移動に使えるもの」を加える。返納特典とタクシー助成を同じページで確認できるようにする。

## 表示の決め方

- 返納特典とタクシー助成が同じ制度の市町では、制度を二重に説明せず、既存の「まとめ」と手順へ案内する。該当するのは加西市・加東市・相生市・太子町・香美町。多可町は公開済みの個別案内を維持する。
- 別の制度がある市町では、既存のタクシー一覧データから対象・助成内容・申し込み先を表示する。返納した人にも対象が広がる場合は、その条件を示す。
- 一般のタクシー助成が確認できない市町や終了した市町では、その状況を表示する。対象を推測で補わない。
- 制度の公式ページと、タクシー一覧データの確認日を表示する。家族向けの「最初のひと言」には市町を選んだ状態で進む。
- 印刷の2ページ制限に合わせ、この追加案内は印刷時に省く。

## データと実装

`data/hyogo-taxi.json` の `guide_relation: same` で同じ制度を明示する。本文は `tools/build.py` から生成し、共通の見た目は `site.css` に置く。多可町の個別案内はそのまま優先する。

## 公開前の確認

1. 29ページだけに追加案内が1件ずつ出て、多可町の案内と他県のページが変わらないこと。
2. 同じ制度を二重計上しないこと。異なる制度では対象・助成・申し込みを混同しないこと。
3. 各市町の公式出典の原文を確認し、制度変更を反映すること。ページ全体の確認日を変更する場合は、返納手続きも含めて確認すること。
4. 390px幅と文字拡大で横にはみ出さないこと。リンク、印刷、コピー、LINE共有が動くこと。
5. 確認用ページをオーナーに見せ、公開の返事を受けてから本番に出すこと。

## 2026年10月3日の確認結果

- 兵庫県の手順ページ30件に移動支援の案内が1件ずつあり、多可町の既存案内は維持した。他県の個別ページは生成結果に差分なし。
- タクシー一覧データの公式リンク40件はすべて開けた。今回対象の29件は公式ページを再取得し、対象年齢・助成額・申込先の数値を機械的に照合した。表記の違いや別ページに説明がある5件は原文を確認した。
- たつの市の高齢者タクシー券は、市の2026年広報で1枚500円と確認できたため「記載なし」を修正した。おでかけ支援券の公式ページも追加した。朝来市の「あさGO」の200円運賃には、市の運行案内を追加した。
- 神戸市・西宮市・加西市・太子町・相生市・朝来市・たつの市の7件で、390px幅・文字拡大・印刷2ページ・コピー・LINE共有を確認した。問題はなかった。
