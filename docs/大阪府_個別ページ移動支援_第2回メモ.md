# 大阪府の個別ページ：移動支援の追加（第2回）

2026年10月3日に公式ページを確認し、既存の個別ページ3件へ「返納後の移動に使えるもの」を追加した。ページ全体の確認日は、返納手順などを再確認していないため変更していない。

| 市町 | 返納特典との関係 | 公式出典 |
|---|---|---|
| 交野市 | 別制度。70歳以上などが対象の年度ごとの外出支援。返納特典との併用可否は公式ページに記載なし | [外出支援制度](https://www.city.katano.osaka.jp/docs/2020032700080/)、[自主返納支援](https://www.city.katano.osaka.jp/docs/2023122100043/) |
| 千早赤阪村 | 個別ページの返納後の移動案内と同じ公共交通利用助成事業 | [村の公共交通利用助成事業](https://www.vill.chihayaakasaka.osaka.jp/kakuka/soumu/soumuseisaku/koukyo_koutsu/takuchike/11872.html) |
| 田尻町 | 返納者向けのタクシー券自体が個別ページの返納特典 | [町のタクシー利用料金助成](https://www.town.tajiri.osaka.jp/kakukanojoho/jigyobu/dobokugesuidoka/2/5110.html) |

交野市は詳しい説明が個別ページ内に既にあるため、移動支援の案内からその節へつないだ。3ページとも一覧からの入口、URLコピー、LINE共有、390px幅と文字拡大、A4印刷2枚以内を確認した。出典リンクもすべてHTTP 200だった。
