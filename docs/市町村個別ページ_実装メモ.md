# 市町村の個別ページ：多可町の実装メモ

## 目的

免許返納の手順を読んだ人が、返納後の移動に使える制度をページ内で見つけ、申込方法まで進めるようにする。家族が読む場合は、同じ市町を選んだ状態で「最初のひと言」に進めるようにする。

## 試作の範囲

- 対象は多可町の個別ページ `hyogo-menkyo-henno/taka.html` だけ。他の市町の個別ページには案内を出さない。
- 「まとめ」と「注意点」の後に、返納後の移動に使えるものへの短い案内を置く。
- 福祉タクシー券は申込手順へ、路線バスは既存の説明へ、家族向けリンクは多可町が選ばれた「最初のひと言」へつなぐ。
- 新しい制度の事実は加えない。既存の `guide` の事実と出典を使う。ページ全体の確認日は変更しない。

## 表示する内容

| 案内 | 要点 | 行き先 |
|---|---|---|
| 福祉タクシー券 | 運転経歴証明書を持つ65歳以上の人が対象。500円券24枚、1年に1冊。利用者負担1,000円 | ページ内の「多可町に申し込む」 |
| 路線バス | 町民向けの多可町乗車ICカード。大人は町内1回100円 | ページ内の「町の路線バス」 |
| 家族向け | 親に話すときの、最初のひと言 | `henno-hanashikata.html?city=taka` |

申込条件や使い方の全文は既存の手順と出典に残す。この案内はページ内の道しるべとし、印刷では省く。

## 公開前の出典確認

2026年10月3日に多可町の[福祉タクシー券交付について](https://www.town.taka.lg.jp/category_guide/detail/id=16269)で65歳以上の運転経歴証明書所持者、500円券24枚、年間1冊、利用者負担1,000円を確認した。同日に[路線バス](https://www.town.taka.lg.jp/bus/)で町民向け乗車ICカードと大人の町内1回100円を確認した。ページ内の「確認」表示は警察手続きなども含む全体の日付なので、2026年9月27日のままにする。

## 完成の確認

1. 多可町のページだけに案内が出る。他の個別ページの内容は変わらない。
2. 3つのリンクがそれぞれ正しい場所に進む。
3. スマートフォン幅390pxと「文字を大きく」で横にはみ出さない。
4. 印刷はA4で2枚以内。既存のコピー・印刷・LINE共有も動く。
5. ほかの市町への展開時は、それぞれの公式出典を再確認する。
