# 市町村の個別ページ：移動支援の展開順

## 現在の順番

既に免許返納の個別ページがある地域を優先する。大阪府の既存16ページが終わったら、埼玉県、福岡県、東京都、神奈川県、熊本県、沖縄県の順に進める。各地域では、返納後に使えるタクシー・バスの支援がある市町を先にし、制度終了・公式ページに記載なしの市町を後にする。公式情報が確認できない場合は、その市町を飛ばして理由を記録する。

大阪府の第3回は四條畷市、河内長野市、茨木市。第4回は、東大阪市、豊中市、摂津市、大阪狭山市、泉南市、熊取町、岬町。これで大阪府の既存個別ページ16件に、返納特典と移動支援の確認結果を同じページで掲載した。埼玉県の第1回は、蕨市、朝霞市、志木市、三芳町、三郷市。第2回は鴻巣市、川越市、越生町。第3回は嵐山町、川島町、久喜市、宮代町。第4回は美里町、秩父市、横瀬町。第5回は行田市、神川町、福岡市。第6回は福津市、新宮町、大刀洗町。第7回は久留米市、福智町、香春町。その後、東京・神奈川の4地域、続けて5地域、熊本県の8地域を確認した。制度の更新や公式ページの状況で順番を見直す。

## 作業単位

公式制度が確認できる既存個別ページを少数ずつ進める。第2回はサブエージェント1人で3地域、第3回は2人で各2地域、第4回は3人で各1地域の公式調査を担当し、親がデータ修正、生成HTML、表示、印刷、リンク、公開結果を確認する。作業前後のCodex週次使用率を記録し、使用率が想定以上に増えた場合は次の地域へ進む前に人数・件数・モデルを見直す。使用率は整数表示のため、1地域ごとの正確な消費量とはみなさない。時刻を決めた自動実行は設定しない。
