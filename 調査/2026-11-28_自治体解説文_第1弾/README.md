## 掲載前の差し戻し基準

- 文ごとに公式原文の箇所、対象、期間、条件を照合する。根拠の弱い文、地名を入れ替えた文、制度一覧の言い換えで終わる文、推測を含む文は保留する。
- 調査して返納特典の記載を見つけられなかったときは、資料名と確認範囲を示す。
- 本文と既存の制度欄で条件・金額・年度が食い違えば、公式原文で確かめて両方を直す。根拠が不足する項目は保留する。
- 執筆後に無作為で3件を抽出し、公式資料から利用条件・予約・乗降の順で読み直して本文との一致を確かめる。

- 下郷町は令和8年度の回覧の対象者、福祉施設入所の除外、500円券30枚、1乗車3枚まで、年度末まで、指定事業者を既存のタクシー欄にも反映した。下郷営業所の番号は事業者の公開案内でも確認した。
- 大宜味村は要綱と村社会福祉協議会の案内に従い、「通院・買い物の交通」欄に対象者、送迎先、申請、片道自己負担を掲載した。
- 東栄町は福祉タクシー券の適用条件・月4枚・片道運賃相当・身体介護料は自己負担を既存のタクシー欄にも反映した。
- 佐井村は資格者証の有効期限3月31日、発行に数日かかること、年度予算の成立後に始まることを併記した。
