## 検証結果

- `python3 tools/build.py` で全体を再生成。日付の記載がない下郷町の回覧について、県一覧でも日付を「記載なし」と表示できるよう生成処理を補った。
- 公開構成・SEOは2,205ページ、1,741市町村、47都道府県でエラー0件。バスデータ47都道府県、Python 97テスト、JavaScriptの計算と家族用メモ・計測・県一覧のDOMテストに合格。
- 変更は市町村35 HTMLと、制度データから再生成した関連6 HTML。対象外の2,164 HTMLとサイトマップ・robots.txtは基点 `c2902c50` とバイト一致。既存のID・name属性106,652件を保持した。うち32市町村は解説カードを外すと既存のHTML構造と一致し、3市町村では制度欄も更新した。
- 35件で支援一覧直後の表示、本文と出典番号の対応、確認日を検証。320px・390pxの通常と文字拡大の140通りで横はみ出しがなく、本文の番号から出典へ移動した。ローカル検証の外部通信は遮断した。
- 本番の下郷町・大宜味村とサイトマップ・robots.txtは読み取り専用のHTTP取得で公開基点とバイト一致。第1弾の候補はローカルで検証した。
- 全国原文検査は神戸市の終了済みICOCAキャンペーン注記1件を検出した。神戸市のHTMLとバスデータは基点と一致する。
- 試作の `audit.py` で基点と候補 `6514823e` を比較。35件すべてで独自本文が増え、計9,760字、1件当たりの中央値は221字増（175〜842字増）。35件中19件が300字以上になり、全国の300字未満は105件から86件に減った。次弾70件の対象は、元の105件のうち今回対象に含めなかった自治体。 [35件の増加量](独自本文の増加.tsv)
