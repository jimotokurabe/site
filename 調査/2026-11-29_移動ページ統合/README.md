# 移動ページ214件の統合と main 取り込み

2026年11月29日（JST）。PR #333 を含む main の `d87d671c` を取り込み、既存の PR #332 を更新した。[PR #332](https://github.com/jimotokurabe/site/pull/332)

## 移した情報

- 旧移動ページの路線・対象地区・利用条件・運賃・運行日・予約と申請・公式出典・確認日は、市町村ページの移動案内（`#rides`）で読める。八王子市では、はちバスの料金、専用乗車券、時刻表・路線図への案内も移した。神戸市西区の掲載範囲とすこやかバスの敬老割引は神戸市の交通欄に掲載する。
- 移し先のない固有の制度情報は0件。旧ページの空欄表示1件、確認先の記録が不足する11自治体の短い表示は、市町村ページの既存表示で扱う。那智勝浦町は県データの日付を表示していたため、既存の市町村側の制度確認日（2026年11月1日）を表示する。[保持検査](preservation.json)
- 全国の `mobility.html` は掲載状況の検索、`east-harima-mobility.html` は外出目的別の検索を提供するため、両ページを公開・サイトマップに残す。検索結果からは該当する市町村の移動案内を直接開く。

## 転送と計測

転送設定は `tools/mobility-redirects.json` に収録した。[旧URL対応表（214組、HTTP確認結果付き）](旧URL対応表.csv)

旧URLはHTTP 200で配信する軽量HTML。0秒の meta refresh と手動リンクは市町村ページの `#rides`、canonical は同じ市町村ページの正規URLを指す。旧URLに noindex とGA4タグは付けていない。転送先の既存タグでページビューを計測する。旧URLのクエリ・UTM・フラグメントは固定の転送先URLに引き継がれず、UTMによるキャンペーン帰属も移らない。旧本文のアンカーIDは市町村ページで利用できる。
